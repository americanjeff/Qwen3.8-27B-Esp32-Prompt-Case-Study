📐 Circuit Description

Power: J1-2 (3V3) → breadboard + rail (red)

GND: J1-1 (GND) → breadboard − rail (blue/black)

LED Circuit:

GPIO4 HIGH (3.3V) → 220Ω resistor → LED anode

LED cathode (flat side) → GND rail

Button Circuit:

GPIO9 (internal pull-up) → pushbutton → GND

LED Current: I = (3.3V − 2.0VF) / 220Ω ≈ 5.9mA
