How current flows: ESP32-C3-DevKitM-1 → breadboard → switch → LED

GPIO4 drives a red LED through a 220 Ω resistor (LED anode → resistor → GPIO4; cathode → GND rail). A pushbutton pulls GPIO9 to GND (internal pull-up enabled). 3V3 feeds the + rail; GND feeds the − rails. Yellow dashes = conventional current (only on closed loops): 3.3 V (internal) → GPIO4 → 220 Ω → LED → − rail → GND pin. Cyan dashes = the tiny input loop through the internal pull-up while the button is pressed (≈ 45 µA). The red 3V3→rail wire carries 0 mA — that rail has no load in this circuit.

Circuit notes

The LED is powered through GPIO4: when the pin is HIGH it is internally connected to the chip’s 3.3 V rail, so the loop is 3.3 V → GPIO4 → 220 Ω → LED → − rail → GND pin. The red rail sits at 3.30 V but carries no current — nothing loads it here.

GPIO9 is a strapping pin (sampled at reset); as a press-to-GND input with the internal pull-up it is perfectly safe for this demo.

ESP32 GPIOs are 3.3 V-only — breadboard rails are fed from 3V3, not 5 V, on purpose.

Built to match the real hardware: pin labels follow the official ESP32-C3-DevKitM-1 header tables (J1/J3, 15 pins each; the port is Micro-USB, not USB-C), and the breadboard is a full-size 830 tie-point board (63 columns × a–j + 4×50 power-rail points).
